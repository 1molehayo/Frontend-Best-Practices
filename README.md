# Front-End Coding Standards

Conventions for HTML, CSS, Sass, Tailwind, JavaScript, TypeScript, testing, Git, and tooling. A project should read as if one person wrote it.

Sass or Tailwind, and TypeScript or JavaScript, depending on the project. The rules underneath those choices are KISS and DRY, on the first page of the guide.

## Read the guide

```bash
pnpm install
pnpm docs:dev
```

The site runs at <http://localhost:5173>. The published copy is at <https://1molehayo.github.io/Frontend-Best-Practices/>.

## Copy into a project

Shared config lives in [`examples/`](examples/). The [Tooling](docs/tooling.md) page says which files to copy for a new project and which to keep on an existing one. The worked example is Harbor.
